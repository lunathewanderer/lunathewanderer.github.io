# Networking 101

## IP addresses, Ports, Protocols, and Sockets

### IP addresses

- An Internet Protocol address (IP address) is a numerical label that is assigned to a device connected to a computer network. IP addresses serve two main functions: network interface **identification**, and location **addressing**.
- Two versions of the Internet Protocol are in common use on the Internet today are IPv4 and IPv6. IPv4 uses a 32-bit system providing about 4.3 billion total addresses, and was exhausted. IPv6 uses a 128-bit system offering a nearly unlimited supply. IPv4 uses numbers separated by dots (like 192.168.1.1). IPv6 uses letters and numbers separated by colons (like 2001:db8::1)
- IP Addresses can be classified as Public, Private, Static, or Dynamic. 

### Ports
- Port is a communication endpoint. It's a logical connection used by programs and services to exchange information, as well as determining which program or service on a computer or server that is going to be used. 
- A port is uniquely identified by a **port number**, associated with the combination of a **transport protocol** and the network **IP address** 
- Ports 0 - 1023 are well-known ports, Ports 1023 - 49151 are registered ports, Ports 49152 - 65535 are private/dynamic ports.

### Protocols

**According to [Cloudfare](https://www.cloudflare.com/learning/network-layer/what-is-a-protocol/):**

*"In networking, a protocol is a set of rules for formatting and processing data. Network protocols are like a common language for computers. The computers within a network may use vastly different software and hardware; however, the use of protocols enables them to communicate with each other regardless.*

*Standardized protocols are like a common language that computers can use, similar to how two people from different parts of the world may not understand each other's native languages, but they can communicate using a shared third language. If one computer uses the Internet Protocol (IP) and a second computer does as well, they will be able to communicate - just as the United Nations relies on its 6 official languages to communicate amongst representatives from all over the globe. But if one computer uses IP and the other does not know this protocol, they will be unable to communicate.*

*On the Internet, there are different protocols for different types of processes. Protocols are often discussed in terms of which OSI model layer they belong to."*

**According to a random [Redditor](https://www.reddit.com/r/explainlikeimfive/comments/3gd428/eli5_network_protocols/):**

*"In networking, a protocol defines one or more message formats used by devices on the network. It defines what is transferred, in terms of how the bits are laid out on the wire. A protocol also usually specifies how different devices on the network should respond to the messages. Many of the core protocols of the Internet are specified by documents called RFC's which are published by the IETF.*

*Usually a protocol has a specific application, a goal that it intends to accomplish:*

- The goal of the IP protocol is to give each connected device an address, and allow packets to be routed. IP doesn't guarantee that data will arrive in order, or at all - of course many applications want data to arrive in order and automatically request retransmission. 
- The goal of TCP is to implement reliable data transfer using the building blocks of IP. 
- The goal of the DHCP protocol is to allow a device that's just connected to a network to request an IP address. 
- The goal of the HTTP protocol is to use the building block provided by TCP (reliable data transfer) to create a way to retrieve documents (usually used by browsers for websites, images, and JavaScript, but there are other uses of HTTP as well).

*A protocol consists of a specification (usually a detailed plain text description of the different messages and their meanings) and an implementation (a combination of software and hardware that does what the specification says). The protocol itself is an abstract idea about how machines should behave. You can find implementations of different protocols in routers and servers - an implementation is just the hardware and/or software that causes the machines to behave in ways specified by the protocol.*

*As you can see, many protocols are specified in terms of other protocols:*

- IP: "I have a physical connection between multiple networks, how do I get universal addressing?"
- TCP: "I have universal addressing provided by IP, how do I get reliable in-order delivery?"
- HTTP: "I have reliable delivery provided by TCP, how do I download/upload files from/to named locations on a server?"

*The OSI model, to this end, is a popular conception of a "stack" of networking problems, where the solution to each problem is a building block to solve the next problem."*

### Sockets

Each network device (or host) has a unique identifier (or address). These are used to ensure data is sent to the correct destination. Examples are:
- MAC (Media Access Control) addresses. Unique identifiers assigned to every device during manufacturing.
- IP (Internet Protocol) addresses. Unique identifiers which define a deviceâ€™s host network and location. They are assigned to every device using the Internet Protocol to communicate.

The combination of an IP address, a port number, and transport protocol forms a unique connection called a socket. A network socket is a software endpoint that lets two programs pass data back and forth across a computer network or the same device. 

The IP address determines the location, while the port number determines the service:

```
Socket = IP address : Port
```

## Computer Network Architecture

> In computer science, computer engineering, and telecommunications, a network is a group of communicating computers and peripherals known as hosts, which communicate data to other hosts via communication protocols, as facilitated by networking hardware.

### Classification

Computer networks are grouped by size and geographic range:
- **PAN (Personal Area Network)**: Connects personal devices like phones and laptops within a range of 10 meters, often using Bluetooth.
- **LAN (Local Area Network)**: Connects computers in a small area like a home, office, or school building for fast data sharing.
- **WLAN (Wireless Local Area Network)**: Works like a LAN, but uses wireless tech like Wi-Fi instead of physical cables.
- **CAN (Campus Area Network)**: Connects multiple LANs across a specific campus, like a university or large office park.
- **MAN (Metropolitan Area Network)**: Spans across an entire city or town to connect multiple smaller networks.
- **WAN (Wide Area Network)**: Connects computers and smaller networks across large distances, countries, or the entire globe.
- **VLAN (Virtual Local Area Network)**: A logical subnetwork created inside a physical network using software configuration to group devices and improve security.
- **VPN (Virtual Private Network)**: Uses encryption over a public network (like the internet) to let users securely access a private network from a remote location.

### Topology

There are two ways to depict a diagram: the **physical** topology which shows actual hardware (routers, switches, cables, and ports in a data center); and the **logical** topology which illustrates how data moves through the network, including subnets, VLANs, and IP addresses.
- **Star**: Connects all devices to a central switch. It is robust and scalable rendering them the most popular, but the whole network fails if the central switch breaks.
- **Bus**: Connects all devices to a single main cable backbone. It is cheap and easy to setup, but very insufficient and prone to data collisions.
- **Ring**: Each device is connected to its neighbour in a ring. Data moves in one direction and low risks of data collisions, but a single break can disrupt the loop, and difficult to adding or removing devices.
- **Mesh**: A mesh network layout connects multiple nodes directly and dynamically to maximize coverage and avoid a single point of failure. Its downside is its high cost, potential for reduced speed through wireless hopping, and the need to place multiple nodes correctly.
- **Tree**: A tree topology, or star-bus topology, is a hybrid network topology in which star networks are interconnected via bus networks. Tree networks are hierarchical, and each node can have an arbitrary number of child nodes.
- **Hybrid**: Combines two or more different topologies together.

### Infrastructure

- A **node** is a device that is attached to a network, and is capable of creating, receiving, or transmitting information over a communication channel.
- A **hub** is exactly what it sounds like: a hub where everybody meets. If one PC sends data on it's cable to the hub, then the hub just passes this to everybody else connected in the same Ethernet cables without discrimination. It is half duplex which means each port can only send or receive at any one time, means that if 4 computers are plugged into a hub and two of them try to send traffic anywhere, there will be collision and the transmissions will be lost.
- A **bridge** operating at the Data Link Layer (Layer 2) of the OSI model, uses MAC addresses to determine whether a frame should be forwarded or filtered. By dividing a network into multiple collision domains, a bridge helps reduce unnecessary traffic and improve overall network performance. Routing allows multiple networks to communicate independently and yet remain separate, whereas bridging connects two separate networks as if they were a single network.
- A **switch** is a box connecting devices within a single network or LAN, taking in a signal in on one port and sends it out to only relevant ports based on MAC address (the physical adress). It is a full duplex, the center in the star topology, operating at the Data Link Layer (Layer 2). You could say it's an advanced hub with a bit more intelligence, being more selective.
- A **modem**, standing for modulator-demodulator, is a hardware device that connects your home or office network to your Internet Service Provider (ISP). It modulates and demodulates signals for internet access via an ISP, as well as assigning the local network a public IP address on the wider internet.
- A **router** is a box connecting multiple local devices or networks together and direct data packets to their correct destinations across the internet, taking in a signal on one port and sends it out to only relevant ports based on IP address. Routers can also allow multiple devices within a private local network to share a single public IP address provided by an Internet Service Provider (ISP). It operates at the Network Layer (Layer 3).
- Essentially, a **gateway** is a **router**, since it is "the literal gateway" to the Internet, bearing the function of a router. It can operate at any layer of the OSI model, acting as a protocol converter when two systems use entirely different rules, languages, or architectures

Internet Protocol suite
The Internet Protocol suite (also known as TCP/IP) outlines how protocols can be combined to enable end-to-end communication between devices over an IP network. It has 4 layers:

Application layer. Defines how network devices create and share data with other applications. It is concerned with using the appropriate protocol for the type of data being sent.
Transport layer. Performs host to host communication.
Network layer (or Internet layer). Responsible for exchanging datagrams across networks.
Link layer. The networking methods which hosts use to communicate. It is the physical mechanism for sending digital data.

### Network security protocols
There are also various protocols which increase network security and prevent cyberattacks like eavesdropping. Common examples include:

SSL (secure socket layer). Creates an encrypted connection between a computer and the server over the internet.
TLS (transfer layer security). The more robust successor to SSL.
HTTPS (hypertext transfer protocol secure). Modifies HTTP to use TSL and encrypt the connection between the web browser and a server.
SSH (secure shell). Provides an encrypted connection between computer and a server. It supports a variety of authentication methods.


Network communication protocols
Network communication protocols provide standards for creating and keeping connections between network devices. The following protocols are key to the functioning of the internet:

TCP (transmission control protocol). Chunks data into packets which can be sent across an IP-based network.
IP (internet protocol). Responsible for assigning sender and destination addresses to the header of a data packet.
UDP (user data protocol). Used for establishing low-latency and loss-toleration in communications between applications.
HTTP (hypertext transfer protocol). Uses TCP/IP to deliver webpage content from a server to a browser.
FTP (file transfer protocol). Used to deliver files between computers on a network.
